## 共享类型

### `item_entry`

> 背包中的一个物品。
> 可堆叠物品（如药水）按 item_id + count 合并到同一格子，
> 不可堆叠物品（如装备）每个独占一个格子。

| 字段 | Tag | 类型 | 数组 | 说明 |
|------|-----|------|------|------|
| uid | 0 | `string` |  | 物品唯一实例 ID，格式 "item_<自增数字>" |
| item_id | 1 | `integer` |  | 物品模板 ID，对应 item_template 表 |
| count | 2 | `integer` |  | 堆叠数量（不可堆叠物品始终为 1） |
| position | 3 | `integer` |  | 背包格子位置索引，从 1 开始 |
| equipped | 4 | `boolean` |  | 是否已装备 |
| extra | 5 | `string` |  | 额外属性，JSON 格式字符串，预留（洗练/强化/附魔等） |

### `effect_entry`

> 物品使用效果。
> 使用消耗品时返回的效果列表，客户端据此播放动画或更新属性。

| 字段 | Tag | 类型 | 数组 | 说明 |
|------|-----|------|------|------|
| type | 0 | `string` |  | 效果类型: "exp"(经验), "hp"(生命), "attr"(属性点) |
| value | 1 | `integer` |  | 效果数值（正数=增益，负数=减益） |

### `chat_message_entry`

> 聊天消息条目，用于历史记录和实时推送。

| 字段 | Tag | 类型 | 数组 | 说明 |
|------|-----|------|------|------|
| from_id | 0 | `integer` |  | 发送者 player_id |
| from_name | 1 | `string` |  | 发送者昵称 |
| msg | 2 | `string` |  | 消息正文，最长 200 字节 |
| timestamp | 3 | `integer` |  | 服务端时间戳（Unix 秒） |

### `package`

> 所有 sproto 消息的信封包装。
> 服务端收到客户端消息时，先用 .package 解包，
> 通过 type 字段分发到对应协议处理器。

| 字段 | Tag | 类型 | 数组 | 说明 |
|------|-----|------|------|------|
| type | 0 | `integer` |  | 消息类型: 0=服务端推送(s2c), 1=错误响应, 其他=请求协议 tag |
| session | 1 | `integer` |  | 会话ID，请求-响应配对用。服务端推送时 session=0 |

### `rank_entry`

> 排行榜条目。

| 字段 | Tag | 类型 | 数组 | 说明 |
|------|-----|------|------|------|
| rank | 0 | `integer` |  | 排名，从 1 开始 |
| player_id | 1 | `integer` |  | 玩家 ID |
| nickname | 2 | `string` |  | 玩家昵称 |
| score | 3 | `integer` |  | 排行依据的分数 |

## login

### C2S（客户端请求）

#### `login` (tag=1)

> 账号密码登录。
> 连接建立后 60 秒内必须调用此协议，否则服务端断开连接。
> 登录成功后返回会话 token，后续请求携带此 token 验证身份。
> 登录失败 5 次后会被临时锁定 300 秒。

**请求:**

| 字段 | Tag | 类型 | 数组 | 说明 |
|------|-----|------|------|------|
| account | 0 | `string` |  | 账号，长度 >= 3 |
| password | 1 | `string` |  | 密码，长度 >= 6 |

**响应:**

| 字段 | Tag | 类型 | 数组 | 说明 |
|------|-----|------|------|------|
| ok | 0 | `boolean` |  |  |
| player_id | 1 | `integer` |  |  |
| token | 2 | `string` |  | 会话 token，32 字符，有效期 24 小时 |
| nickname | 3 | `string` |  |  |
| level | 4 | `integer` |  |  |

#### `register` (tag=2)

> 注册新账号。

**请求:**
